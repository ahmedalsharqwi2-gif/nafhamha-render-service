## معيار القبول قبل أي تعديل كود

1. **قبل:** رندر عينة 30–45s من الحلقة نفسها بالصوت الحقيقي + قياس بالبوابة.
2. **بعد:** نفس العينة، ونفس الأداة، ونفس المدة — فرق مقيس لا موصوف.
3. **العتبات كما هي:** static ≤ 30%، أطول سكون ≤ 1.5s، متوسط التغيير ≥ 1.9 (مرجع: 29.9% / 1.5s / 1.93).
   لا تُخفَّض لتمرير أي تغيير.
4. **المناطق الآمنة:** مرجع نفهمها من `brand/nafhamha-identity.json` v1.2 —
   نص x=52–596، top=80، الكابتشن 948–1080، الفوتر 1098.
   تعارض قائم يجب حسمه: `src/visualTemplate.ts` يضع captionBottom=832، والهوية 1080.
